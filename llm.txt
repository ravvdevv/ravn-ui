# RAVN UI - LLM Guide
A condensed, high-density reference for RAVN UI (v1.1.3). 
Philosophy: Premium, Minimal, CDN-first.

## 1. Quick Start (Boilerplate)
```html
<!DOCTYPE html>
<html lang="en" data-theme="zinc">
<head>
    <link rel="stylesheet" href="https://unpkg.com/@ravn-ui/core/dist/ui.css">
    <link rel="stylesheet" href="https://unpkg.com/@ravn-ui/core/dist/themes.css">
</head>
<body>
    <main class="flex flex-col gap-8 p-12">
        <h1 class="hero">Hello Elite SaaS</h1>
        <button class="btn btn-primary" onclick="RAVN.showToast('Ready.')">Action</button>
    </main>
    <script src="https://unpkg.com/@ravn-ui/core/dist/ui.js"></script>
</body>
</html>
```

## 2. Core Components
- **Buttons**: `<button class="btn [btn-primary|btn-outline|btn-ghost] [btn-sm]">Text</button>`
- **Cards**:
  ```html
  <div class="card">
    <div class="card-header"><h3>Title</h3><small>Sub</small></div>
    <div class="card-content">Body content here.</div>
    <div class="card-footer"><button class="btn btn-sm">Confirm</button></div>
  </div>
  ```
- **Modals**:
  ```html
  <button data-modal-target="m1">Open</button>
  <div id="m1" class="modal">
    <div class="modal-backdrop"></div>
    <div class="modal-content">
      <h3>Title</h3><p>Desc.</p>
      <button data-modal-close>Close</button>
    </div>
  </div>
  ```
- **Dropdowns**:
  ```html
  <div class="dropdown">
    <button data-dropdown>Toggle</button>
    <div class="dropdown-menu"><button class="dropdown-item">Action</button></div>
  </div>
  ```
- **Alerts**: `<div class="alert [alert-success|alert-warning|alert-error]">Text</div>`
- **Stat Cards**: Use `.trend.trend-up` or `.trend.trend-down` for metrics.

## 3. Themes
Apply globally: `<html data-theme="name">`.
Available: `light`, `dark`, `claude`, `midnight`, `supabase`, `linear`, `zinc`, `forest`, `indigo`.

## 4. JS API (RAVN)
- `RAVN.setTheme(string)`: Persist theme change.
- `RAVN.modal(id, 'open'|'close')`: Manual control.
- `RAVN.showToast(string)`: System notification.
- `RAVN.copy(text, msg)`: Clipboard + Toast.

## 5. Design Tokens
- Colors: `--primary`, `--background`, `--foreground`, `--muted`, `--border`.
- Radius: `--radius` (0.375rem).
- Spacing: `--space-1` (0.25rem) to `--space-12` (3rem).
